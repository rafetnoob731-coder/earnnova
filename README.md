# EARNNOVA - Premium Earning Platform

🚀 **Earn money by watching ads, completing tasks, and referring friends.**

## Features

- ✅ **Watch Ads** - Earn real rewards by watching advertisements
- 🔗 **Referral System** - Earn commissions from referrals
- 💰 **Binance Withdrawals** - Withdraw earnings via Binance Pay
- 🎯 **Task Center** - Complete tasks for additional earnings
- 📊 **Premium Dashboard** - Real-time analytics and statistics
- 🔐 **Secure Authentication** - Firebase Auth + Supabase DB
- 🛡️ **Anti-Fraud System** - Advanced fraud detection
- 📱 **Mobile Optimized** - Works perfectly on all devices

## Tech Stack

- **Backend:** PHP 8+
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Database:** Supabase (PostgreSQL)
- **Authentication:** Firebase Auth
- **Real-time:** Firebase Realtime Database
- **Deployment:** Vercel

## Quick Start

1. Clone the repository:
```bash
git clone https://github.com/yourusername/earnnova.git
cd earnnova
```

2. Copy environment file:
```bash
cp .env.example .env
```

3. Configure your environment variables in `.env`

4. Deploy to Vercel:
```bash
vercel --prod
```
